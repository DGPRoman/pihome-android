# pihome-android

An Android client for [pihome-hub](https://github.com/DGPRoman/pihome-hub): switch the
relays, read the sensors and manage who has access to the house, from a phone.

**Status:** planned, not yet usable. The work is tracked in this repository's issues and
on the [Smart Home](https://github.com/users/DGPRoman/projects/3) board.
